### Анализ кода

Проверил все места с обработкой JSON и кодировкой:

✅ **CSV читается правильно:** `encoding="utf-8-sig"`
✅ **JSON dumps правильно:** `ensure_ascii=False` везде
✅ **API запросы правильно:** OpenAI клиент автоматически использует UTF-8

❌ **Проблема только в выводе в консоль:** Windows консоль не поддерживает UTF-8 по умолчанию

### Решение

Все места с `print()` используют безопасную кодировку:
```python
text_safe = text.encode('ascii', 'replace').decode('ascii')
```

Это **правильное решение** для Windows консоли. Кириллица заменяется на `?` только в **логах**, но:
- ✅ Данные в API передаются корректно (UTF-8)
- ✅ Результаты в файлах корректны (UTF-8)
- ✅ Судья получает корректный текст (UTF-8)
