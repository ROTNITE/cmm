# Changelog: Eval Logging System

## Добавлено

### Новые файлы

1. **Lib/eval_logger.py** (7.2 KB)
   - Класс `EvalLogger` для интерактивного логирования
   - Методы для логирования различных событий:
     - `case_start()` / `case_end()` - начало/конец кейса
     - `stage_start()` / `stage_end()` - стадии (baseline, cmm, judge)
     - `agent_start()` / `agent_end()` - работа агентов
     - `ai_call()` - вызовы AI с подсчетом токенов
     - `router_decision()` - решения роутера
     - `expert_contribution()` - вклад экспертов
     - `plan_critique()` - критика плана
     - `moderation_decision()` - решения модератора
     - `warning()` / `error()` / `info()` - сообщения
     - `summary()` - итоговая статистика
   - Цветной вывод в консоль
   - Подсчет общего количества токенов и вызовов
   - Оценка стоимости

2. **Lib/AI_request_instrumented.py** (2.0 KB)
   - Обертка над `send_to_AI` с отслеживанием токенов
   - Оценка количества токенов (~0.75 на слово)
   - Логирование каждого вызова с параметром `log_purpose`

3. **Lib/state_machine_instrumented.py** (1.3 KB)
   - Обертка над `run_cmm_state_machine`
   - Логирование запуска и завершения CMM

4. **test_eval_logging.py** (1.1 KB)
   - Тестовый скрипт для проверки логирования
   - Запускает eval на 2 кейсах

5. **docs/eval_logging.md** (5.9 KB)
   - Полная документация на английском
   - Примеры использования
   - Описание компонентов

6. **docs/eval_logging_ru.md** (3.6 KB)
   - Краткая инструкция на русском
   - Быстрый старт
   - Примеры вывода

### Изменения в существующих файлах

1. **cmm/eval.py**
   - `_real_baseline()`: добавлено логирование стадии baseline
   - `_real_cmm()`: добавлено логирование стадии CMM с деталями trace
   - `judge_case_with_llm()`: добавлено логирование стадии judge
   - `_run_real_judged_eval()`: добавлена инициализация логгера и вывод итоговой статистики
   - Все функции используют `AI_request_instrumented` вместо `AI_request`

2. **Lib/orchestrator.py**
   - Добавлена проверка переменной окружения `CMM_EVAL_LOGGING`
   - При включенном логировании использует `state_machine_instrumented`

## Использование

### Автоматическое включение

```bash
python -m cmm.eval --dataset path/to/dataset.csv --mode real --judge-mode llm
```

### Тестовый запуск

```bash
python test_eval_logging.py
```

## Что логируется

- ✅ Начало и конец каждого кейса
- ✅ Все стадии: baseline, CMM, judge
- ✅ Каждое обращение к AI с количеством токенов
- ✅ Решения роутера (режим и сложность)
- ✅ Вклад каждого эксперта
- ✅ Результаты критики плана
- ✅ Решения модератора
- ✅ Предупреждения и ошибки
- ✅ Итоговая статистика: вызовы, токены, стоимость

## Технические детали

- Оценка токенов: ~0.75 токена на слово
- Оценка стоимости: ~$0.21 за 1M токенов (DeepSeek)
- Цветной вывод с использованием ANSI escape codes
- Автоматический flush для интерактивности
- Не влияет на результаты evaluation

## Совместимость

- ✅ Работает с существующими eval тестами
- ✅ Не ломает существующий код
- ✅ Можно отключить через `set_logger_enabled(False)`
- ✅ В mock режиме логирование не активно
