**Дата:** 2026-05-08  
**Статус:** ✅ ЭТО НЕ БАГ, ЭТО ОГРАНИЧЕНИЕ WINDOWS КОНСОЛИ

## Что происходит?

В консоли и в `console.log` видим:
```
Query: ??? ????? ???????????? ??????????????
```

Вместо:
```
Query: Что такое коллективная модерация?
```

---

## Где данные корректны?

### ✅ В файлах результатов (UTF-8)

```python
# cases_incremental.jsonl
{"case": {"query": "Что такое коллективная модерация?"}}

# Проверка:
query.encode('utf-8')[:20].hex()
# d0a7d182d0be20d182d0b0d0bad0bed0b520d0ba
# = "Что такое к..."
```

### ✅ В API запросах (UTF-8)

OpenAI клиент автоматически отправляет JSON с UTF-8:
```python
messages = [{"role": "user", "content": "Что такое..."}]
response = client.chat.completions.create(messages=messages)
```

### ✅ В датасете (UTF-8)

```python
with open("cmm_dataset_v2.csv", "r", encoding="utf-8") as f:
    # Читается корректно
```

### ✅ В ответах судьи (UTF-8)

Судья получает корректный текст и оценивает правильно.

---

## Где данные НЕ корректны?

### ❌ Только в консоли и console.log

Причина: строка 1200 в `eval.py`:
```python
query_display = query.encode('ascii', 'replace').decode('ascii')
```

Это **специально** сделано для Windows консоли, которая не поддерживает UTF-8 по умолчанию.

---

## Почему так сделано?

### Без этой конвертации:

```python
print(f"Query: {query}")  # query = "Что такое..."
```

**Результат в Windows консоли:**
```
UnicodeEncodeError: 'charmap' codec can't encode characters
```

Программа **падает** с ошибкой!

### С конвертацией:

```python
query_display = query.encode('ascii', 'replace').decode('ascii')
print(f"Query: {query_display}")
```

**Результат:**
```
Query: ??? ????? ???????????? ??????????????
```

Программа **работает**, но кириллица заменена на `?`.

---

## Это проблема?

### НЕТ, потому что:

1. ✅ **Данные в API корректны** - судья получает правильный текст
2. ✅ **Результаты в файлах корректны** - можно читать с UTF-8
3. ✅ **Оценки корректны** - судья оценивает правильный текст
4. ❌ **Только логи в консоли нечитаемы** - но это не влияет на работу

### Альтернативы:

**Вариант 1: Убрать конвертацию**
```python
# Убрать строку 1200
query_display = query  # Без encode('ascii', 'replace')
```

**Результат:** Программа будет падать с `UnicodeEncodeError` в Windows консоли.

**Вариант 2: Настроить Windows консоль на UTF-8**
```cmd
chcp 65001
```

**Результат:** Может помочь, но не гарантировано на всех версиях Windows.

**Вариант 3: Оставить как есть (рекомендуется)**

Логи в консоли нечитаемы, но:
- Программа работает стабильно
- Все данные корректны
- Результаты можно читать из файлов

## Как читать результаты?

### Вместо консоли, читай файлы:

```python
import json

# Читаем кейс
with open('eval_results/run_final/cases_incremental.jsonl', 'r', encoding='utf-8') as f:
    case = json.loads(f.readline())
    print(case['case']['query'])  # Корректная кириллица!
```

### Или используй Python для вывода:

```python
import csv

with open('eval_results/run_final/results_incremental.csv', 'r', encoding='utf-8') as f:
    reader = csv.DictReader(f)
    for row in reader:
        # Все поля с кириллицей корректны
        print(row['case_id'], row['winner'])
```
