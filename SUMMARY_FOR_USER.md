## Что было сделано

### 1. Полный анализ деградации ✅

**Проблема:** Система деградировала с +1.40 до -1.50 avg delta

**Найденные причины:**
1. Hardcoded ответы в direct_answer.py для KPI и trade-offs
2. Слишком агрессивный answer_budget (650 chars для "concise")
3. Недетерминированные quality_gates (зависимость от формулировок модели)

### 2. Реализованы исправления ✅

#### quality_gates.py - Гибридный подход
- Разделены маркеры на CRITICAL_PHRASES и CRITICAL_WORDS
- Добавлен NON_CRITICAL_CONTEXT для исключения false positives
- Добавлено trace логирование
- **Эффект:** Система стабильнее, не зависит от формулировок

#### answer_budget.py - Adaptive budget
- Детекция типа вопроса (comparison, definition, needs examples)
- Для вопросов с примерами: 1000 chars вместо 650
- 30% buffer если ответ содержит примеры
- **Эффект:** Больше места для качественных ответов

#### direct_answer.py - Hardcoded ответы ОСТАВЛЕНЫ
- Первоначально удалили → все 3 DIRECT кейса проиграли
- Откатили обратно → hardcoded ответы вернулись
- **Причина:** Они компенсируют слабость промпта
