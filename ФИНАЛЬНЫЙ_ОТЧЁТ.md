### Фаза 2: Улучшение качества CMM (коммит 95d1f13)

**Проблемы:**
- DIRECT mode: generic advice, no examples (-1.0 на всех кейсах)
- Planner: fallback_repair, слабые prompts
- Experts: слишком короткие (100 chars), слабые prompts

**Решения:**

#### 1. `direct_answer.py` - РАДИКАЛЬНОЕ УЛУЧШЕНИЕ
```
Было:
- "Answer the user's simple low-risk request directly and concisely"
- 700 tokens
- Нет инструкций про качество

Стало:
- Detailed prompt с quality standards
- Требования: SPECIFIC, CONCRETE, EXAMPLES, ACTIONABLE, CLEAR
- Explicit инструкции для definition questions
- 1200 tokens (+71%)
```

#### 2. `plan_development.py` - УЛУЧШЕНИЕ PLANNER
```
Было:
- "Ты планировщик. Создай план ответа."
- detailed: 1000 tokens

Стало:
- Expert-quality prompt
- Требования: SPECIFIC, ACTIONABLE, COMPREHENSIVE, RISK-AWARE
- detailed: 1500 tokens (+50%)
- quick: 800, comprehensive: 2000
```

#### 3. `expert_agent.py` - УЛУЧШЕНИЕ ЭКСПЕРТОВ
```
Было:
- "ONE SHORT SENTENCE (max 100 chars)"
- 500 tokens
- Нет инструкций про качество

Стало:
- Quality-focused prompt
- Требования: SPECIFIC, EVIDENCE-BASED, RISK-AWARE, ACTIONABLE
- "1-2 sentences (max 200 chars)"
- 800 tokens (+60%)
```
